# 1. FÓRMULAS Y ALGORITMO DE CÁLCULO DEL ÍNDICE SINTÉTICO (ISMS)

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **🧮 SISTEMA METODOLÓGICO DE PONDERACIÓN Y CÁLCULO DE RESULTADOS\**                                                                                                                                                       |
| Cada Instrumento Especializado de Nivel 2 aplica un algoritmo de doble vector de evaluación:\                                                                                                                             |
| \                                                                                                                                                                                                                         |
| 1. Ponderación de Preguntas Técnicas de Selección Única (60% del peso total):                                                                                                                                             |
|                                                                                                                                                                                                                           |
| Cada reactivo técnico de opción múltiple otorga una puntuación discreta. El subtotal técnico se calcula mediante:\                                                                                                        |
| Score_Tecnico = ( Puntos_Obtenidos / Puntos_Maximos ) \* 100\                                                                                                                                                             |
| \                                                                                                                                                                                                                         |
| 2. Normalización del Ranking de Borda en Reactivos Rompehielos -R00 (40% del peso total):                                                                                                                                 |
|                                                                                                                                                                                                                           |
| Para los reactivos donde el aplicante ordena por impacto N factores (1 = Máximo dolor / gravedad; N = Menor dolor), la puntuación ponderada de severidad Borda se normaliza en escala 0-100 mediante la fórmula inversa:\ |
| Borda_Score_i = ( ( N - Rango_i + 1 ) / N ) \* 100\                                                                                                                                                                       |
| (Donde N es el número de factores a ordenar y Rango_i es la posición asignada por el usuario de 1 a N).\                                                                                                                  |
| \                                                                                                                                                                                                                         |
| 3. Índice Sintético de Madurez Sectorial (ISMS):\                                                                                                                                                                         |
| ISMS = ( 0.60 \* Score_Tecnico ) + ( 0.40 \* Borda_Score_Sourcing_y_Operaciones )\                                                                                                                                        |
| \                                                                                                                                                                                                                         |
| El puntaje final ubica a la empresa en uno de los 4 Cuadrantes Estratégicos de Madurez, generando un perfil de diagnóstico automatizado y la asignación del Plan de Intervención a 6 y 12 meses.                          |
+===========================================================================================================================================================================================================================+
